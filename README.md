# ALERTORA AI — Hyperlocal Convective Weather Nowcasting Platform

> **Tagline:** *"Predict Early. Prepare Smart. Save Lives."*  
> **Smart India Hackathon Problem Statement:** **SIH26084** — *Convective scale nowcasting for Thunderstorms, Hail & Cloudbursts (06 hr)*

---

## 🌩 System Overview

**ALERTORA AI** is an advanced AI-powered severe weather disaster early-warning and convective nowcasting platform designed for Smart India Hackathon. The platform predicts severe weather hazards (thunderstorms, Cloudbursts, hailstorms, high-density lightning strikes, and severe downburst winds) up to 6 hours in advance by fusing multi-sensor telemetry:

- 📡 **Doppler Weather Radar (DWR)** — Reflectivity (dBZ), Vertically Integrated Liquid (VIL), Storm velocity
- 🛰 **INSAT-3D / 3DR / 3DS Satellite Imagery** — Thermal Infra-Red (TIR) & Water Vapor brightness temperature drops
- ⚡ **Ground-Based Lightning Networks** — High-precision Cloud-to-Ground (CG) strike localization
- 🌡 **Automatic Weather Stations (AWS)** — Ground pressure drops, humidity spikes, and dewpoint convergence
- 🌧 **Automatic Rain Gauges (ARG)** — Sub-hour rainfall accumulation rates

> **Disclaimer:** *This application is a Smart India Hackathon prototype demonstration. Predictions are generated by experimental AI models with confidence scores and are not official IMD weather forecasts.*

## ✨ Key Features & Capability Matrix

1. **Futuristic GIS Command Center Dashboard**:
   - Dark glassmorphism interface styled after government emergency operation centers and AI weather intelligence hubs.
2. **Interactive GIS Weather Map (Leaflet Engine)**:
   - Centered on Tamil Nadu / Chennai region with location search and GPS switch.
   - 9 switchable map layers: Radar Reflectivity, Satellite Cloud, Lightning Density, Rainfall Intensity, Thunderstorm Prob, Hail Prob, Cloudburst Risk, Wind Risk, AI Risk Zones.
   - Color-coded hazard risk polygons (🟢 LOW, 🟡 MODERATE, 🟠 HIGH, 🔴 EXTREME).
   - Custom coordinate picker opening location weather profile drawer.
3. **AI Nowcast Timeline (Next 0–6 Hours)**:
   - Hour-by-hour timeline selector (+0H to +6H) dynamically updating Thunderstorm %, Hail %, Cloudburst %, Lightning %, and Rainfall rates.
4. **Storm Arrival Live Countdown**:
   - Live ticking digital timer countdown (`01:24:36`) targeting active convective cells.
5. **AI Safety Advisor (Precautions Engine)**:
   - Automated response procedures split into **Government / Emergency Operations (EOC)** and **Public / Citizens**.
6. **Government Emergency Operations Center (EOC)**:
   - District-level risk matrix with filterable tables, vulnerable infrastructure counts, and automated warning trigger actions.
7. **Public Safety Mode ("My Safety")**:
   - Mobile-first simplified citizen dashboard with large high-contrast risk banner, storm countdown, and 5-step checklist.
8. **Interactive Demo Mode ("Start Storm Simulation")**:
   - Interactive button to simulate storm trajectory across map, dynamically update reflectivity, escalate hazard probabilities, and trigger audio warning alerts.
9. **Explainable AI (XAI) Panel**:
   - Prototype feature contribution breakdown bars (Radar Reflectivity +34%, Cloud-Top Temp -22%, Lightning +18%, CAPE +14%, Moisture +12%).
10. **Backend-Ready REST API & Database Schemas**:
    - Modular JavaScript API client (`js/api.js`), Python FastAPI backend (`backend/main.py`), and PostgreSQL/PostGIS spatial schemas (`backend/schema.sql`).

## 🚀 How to Run the Application

### Option A: Standalone Web Prototype (Instant Demo)
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari). No `npm` or local web server required!

```bash
# Double click index.html or launch via Python simple server
python -m http.server 8080
# Open http://localhost:8080 in browser
```

### Option B: Running the Python FastAPI Backend
```bash
# Install dependencies
pip install -r backend/requirements.txt

# Start FastAPI server
uvicorn backend.main:app --reload --port 8000
```
- Open backend API docs: `http://localhost:8000/docs`
- Set `this.useLiveBackend = true` in `js/api.js` to connect frontend to Python backend.
